# Nova Poshta Card — після встановлення

## 1. Додай картку в Lovelace

```yaml
type: custom:nova-poshta-card
title: Нова Пошта
```

## 2. Переконайся що інтеграція встановлена

Картка потребує сенсорів від інтеграції:
👉 [homeassistant-nova-poshta](https://github.com/igorolesko/homeassistant-nova-poshta)

Сенсори визначаються **автоматично** — додаткова конфігурація не потрібна.
